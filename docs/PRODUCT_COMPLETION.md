# 墨脈 商品完成への受入計画

2026-10-23。ユーザー目標は素材・効果音・BGMを別チャットで制作しながら商品完成版まで進めること。PCαや見た目の試作だけでは完了としない。公開/課金契約/ストア提出/リポジトリ分割は既存の承認境界を維持する。

## 分担
- 本室: ゲームコード、統合、Unity検証、ビルド、STATE/TASKS、コミット。
- 墨脈 — グラフィック・素材制作室: art-source/とdocs/ART_DELIVERY.md。敵/枝/攻撃/核はSUMI描画を維持。
- 墨脈 — 効果音・BGM制作室: art-source/audio/とdocs/AUDIO_DELIVERY.md。オリジナルWAV、再生成元、由来、ループ/波形検査。本室が採用し組み込む。
- 共有チェックアウト。担当外編集・Unity同時操作・担当側git操作を避ける。
