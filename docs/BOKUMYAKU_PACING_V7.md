# 墨脈 v0.7 — 初回周回と育成後の再評価

開始397b666、2026-10-22 JST。G-V2-05の続き。ゲーム専用範囲のみ。描画エンジンと通常セーブを保護する。

## 観察と今回の条件

v0.6のFarming/Point/Balanced/meta0をseed1..30で追跡。短命seed4/20/25/28はW10ボスから4ダメージを受ける。4/20/28はW20ボスも通し、25は重装が続いて敗北。全30件でW10ボスの撃破11、侵入19。ボスは10秒以上射程内にいるため、「一度も射程に入らない」という説明は支持されない。圧力/最大角度の穴だけで短命を説明せず、複数枝から狙える時間と標的競合を調べる。

最大3案を独立に比較する。現行ソースを直接調整し続けず、メモリ内の変種で測定する。

1. FarmingがHP6以下で有償修復を優先、最大2回。既存の25/38墨を払い1秒の購入枠を使う。
2. 初期ボスのHP係数をW10で8、W20で10、W30以降12へ段階化。全構成共通。
3. 枝分岐の開き角だけ±0.35→±0.65radへ変更。全構成共通。

G05は標準初回seed1..30の全件300〜480秒、候補確定後は未使用31..50の全件でも確認。G04は既存の同seed/同武器比較を維持（Pointは深度/効率各8/10以上、全6武器各48/60以上かつ各武器6/10以上）。未達を除外・閾値変更・時間による強制終了で隠さない。3案で探索を止め、改善だけなら未達を明記する。

## 育成の測定

20自然周回×Farming/Record×周回後の最安恒久購入/無購入で80条件。最安購入は測定方針であり製品に自動恒久購入を追加したものではない。初達成報酬と通常報酬を分離する。

さらに19周Farming育成後の同じmetaを複製し、Point/Balancedのseed1..10を両構成で比較。育成量が異なる20周同士の最高Wave逆転だけで役割の欠陥と断定しない。この同meta比較ではRecordは1勝3同点6敗となり、初期G04合格を育成後まで拡張できないことが分かった。

## 互換と検証

戦闘/購入処理を採用変更する場合はrules3とし、途中のrules1/2は元の計算を継続。変更前の実Unity DLLからFarming/Recordの6000/6900tickと終端を採取済み。旧版互換、自己snapshot復元、未来一致をUnityと独立C#で検証する。

結果画面の通常結晶効率へ初達成ボーナスが混ざる表示も修正し、侵入した敵の情報を表示する。比較スクリプトは戦闘時間+再出撃待機3秒、画面は戦闘時間当たりなので分母を区別する。

検証をUnityコンパイル/NUnit、実画面、PC Player、数値比較に分け、確定結果はQA_AND_EVIDENCE.mdへ記録する。初回尺・育成速度・プレイの楽しさ・美術・実機を別の受入として扱う。

## 育成後の未達

旧rules2の20周育成試験ではFarmingが54回、Recordが29回の恒久強化を購入。上限到達はなく、資金は増えるが費用も増す。Farming初周13回の恒久購入は仮経済の観測値で、適切なテンポという受入ではない。

確定rules3でも同固定meta14/13/14/12を再測定したところ、Recordは1勝2同点7敗、平均−1.4Wave、Farming効率は10/10勝ち。これは旧v6の19周育成を由来とする固定評価点で、v0.7の20周連続育成を実施したという意味ではない。初期meta0のG04合格を、育成後の役割維持へ拡張できない。

次の有限検証候補は、Recordの供給条件を維持して後半の分岐上限を6→9へ拡げること。現在は未実装・未測定。12末端にする前にSupply18を要求すれば序盤の供給分散を抑え得るが、実効火力/費用/配置の検証が必要。今回は追加の戦闘候補を増やさず、未達を引き継ぐ。
