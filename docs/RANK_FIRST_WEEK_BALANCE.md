# 段位別・初週の有限候補比較
2026-10-24 / source f72af05 / rules8。ライブ係数とセーブは未変更。

## 条件
1日1時間、7日7時間のシミュレーション時間。seed42/73/101から周回ごと+1、点墨/Farming、研究は最低Lv優先（同LvはDamage/Supply/Growth/Harvest）。前段位100完了後、次の周回は最高解放段位を選ぶ。収益最適化は行わない。未終了周回の報酬は先取りしない。
価格は3案共通でLv20までmax(現行価格,500+25×Lv)。これは未採用の500案であり現在のゲーム価格ではない。攻撃研究効果のみ現行/1.18^Lv/1.30^Lvを比較。Lv20超は候補のLv20倍率から既存二次式へ接続。
Recordは時点の研究を用いた時間枠外の能力診断。60000tickで打切り、censored=trueは敗北記録ではない。実際の1/7時間到達はtierBestで判定。

## 結果（3seed範囲）

初回敗北は全案共通366.63〜420.8秒（6.11〜7.01分）、初回研究は全系列3周で購入。
1.18案は7時間中の購入が起きた周回30/31/30のうち、前購入から2〜3周を満たすのは4/3/3回。一度に複数購入する周回は21/20/19回。初回だけの合格で全期間合格としない。
1.30案の7時間Record診断は全系列2000秒・Wave166で打切り。この166は最高到達上限ではない。通常Farming周回では既に三段446〜486に達した。

## 判断と次の実装判断
3候補とも全目標を満たさず採用保留。比較案を増やし続けない。1.30の強化方向は棄却し、1.18の成長形を次の費用設計の固定条件とする。現行の「低い研究効果＋初期だけ高い価格」では長期の記録更新が遅く、効果だけ増やすと報酬が価格を追い越す。
次は同じ1.18効果に対して、2〜3周分の通常結晶収益と価格を各Lvで照合し、既存価格表の傾きを修正する。初回500を保ち、段位倍率込みの収益で校正。実装採用時には新rules/価格版/旧保存継続と短い回帰試験が必要。
