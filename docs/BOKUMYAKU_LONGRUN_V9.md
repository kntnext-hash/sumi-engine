# 墨脈 v0.9 — 数万Waveの実行・保存基盤

2026-10-22。基点9639f7e。ユーザーの数万Wave方針を受け、初回5〜8分の全条件一致より長期進行の基盤を優先する。今回の範囲は実行・数値境界・保存・旧ルール互換。到達できる育成曲線や面白さの完成とは分ける。

## ルール契約

- 新規rules5は100,000Wave/36,000,000tickを上限とする（30tick/s、12秒/Wave）。現実時間では1倍速で約13.9日分。実際にその時間放置した検証とは言わない。
- 旧rules1〜4は60Wave/21,600tickと従来計算を保つ。従来のWaveLimit/MaxTicks定数は互換用で、新規処理はルール別RunWaveLimit/RunTickLimitを参照する。
- Wave1〜60のHPと報酬は旧式を維持。61以降の基礎HPはHP60×(1+0.036×(Wave−60))²。速度倍率は2.5上限。出現率は従来4.8/秒上限。
- 墨報酬のWave倍率は60まで1+0.018×Wave、61以降は2.08+ln(1+(Wave−60)/60)。採墨と通常結晶の式は維持。新しい費用や有料機能は追加しない。
- 同時存在は敵96、領域96、枝ノード64、先端12を維持。Waveに比例した履歴配列を作らない。
- 保存ファイル世代6へコピー移行し、schema3/configv3を維持。旧ファイルとbakは保持。進行中の周回は旧rules、新規出撃からrules5。新世代が破損しても古い別世代へ巻き戻さない。

## 数値上界

最大Waveの基礎HPは約2.005×10¹⁰、ボス12倍でも2.406×10¹¹で保存上限10¹²以内。通常出現親は保守的に4,320,001体、ボス10,000体、全通常敵が分裂した場合もID12,970,003以内。最速敵は157.5/秒以内。

墨報酬倍率を安全側10、恒久採墨倍率1.6、通常敵yield最大2、ボス12で評価すると、累計墨560,640,128以内。撃破点140,160,032以内、結晶11,212,802以内。新rulesの保守保存上限は墨600,000,000、撃破点150,000,000、結晶12,000,000、敵counter13,000,000。上限超過を無言で切り捨てる処理は入れない。

恒久結晶残高は既存int、累計はlong。残高上限で精算できない場合は原子的に失敗し、報酬消失や巻戻しを起こさないことを検証する。長期の通貨型拡張は別の設計判断として残す。
