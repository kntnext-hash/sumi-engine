# 墨脈 v0.10 — 火力の長期育成

基点bc04d5b。v0.9の10万Wave基盤に対し、火力強化が途中で上限に達する問題を扱う。今回は火力の育成幅を拡張し、周回報酬で研究を購入する収支を検証する。数万Wave攻略や長期経済の完成を前提にしない。

## 契約

- 新規rules6のみ、周回「筆撃」の上限を100へ拡張。Lv30までは旧式の費用と威力。30超の威力は1.10^30×1.12^(Lv−30)、購入費用はceil(Cost30×(1+0.03×(Lv−30))²)。他6強化の上限は維持する。
- 恒久「祖墨」の上限を100へ。Lv20まで既存倍率1+0.025×Lv、20超は1.5×(1+0.025×(Lv−20))²。費用20まで旧式、20超はceil(Cost20×(1+0.05×(Lv−20))²)。他3研究は20上限を維持。
- 恒久育成は結晶を消費し、次の出撃から反映。戦闘中は研究を購入できない。高レベルを無料で配布しない。
- 旧rules1〜5の途中状態は従来の上限と式を保持。旧ルールに筆撃31/祖墨21以上を混ぜた保存は拒否。UIも実際の周回ルールの上限を参照する。
- 保存先v7へコピー移行。v6以下の原本・バックアップを保持し、v7破損時に旧世代へ巻き戻さない。schema3/configv3は維持。
- 採墨、撃破報酬、敵出現数、同時存在数は変更しない。増加する攻撃量は単発・持続・累積を分けて上界検査し、旧ルールの検証範囲を緩和しない。

## 有限比較

3候補: Aは筆撃80/指数1.10維持、Bは100/1.10維持、Cは100/30超1.12。共通の二次費用と恒久倍率で比較する。候補の500Wave観測上限に到達した周回はRunningのまま記録し、自然敗北や完走と読み替えない。Cを採用候補として固定し、追加の上限2000Wave観測と複数seedの旧取得範囲比較を行う。

固定した高レベルでの性能と、実際に結晶を集めて研究する速度は別に検査する。前者だけで成長テンポを合格にしない。実測値はevidence/growth-v10-*とprogression-v10-*、UnityとWindowsはQA_AND_EVIDENCE.mdの確定記録を参照。

## 受入と残件

費用・倍率・上限・残高の境界、旧保存の未来一致、新研究の購入と次周反映、保存復帰を合格条件とする。長期育成の全期間、数万Wave攻略、6武器全ての役割保証、実機連続運転、美術・音・オンラインは残件。今回の候補比較は3案で区切る。

数値上界: 最大単発約8,126,829、最大領域/tick約506,573で各1e9未満。全36,000,000tick・最短間隔7tick・12末端・1射96体という安全側の直接攻撃に、96敵×2領域の毎tick加算を足しても累積5.165e16未満。rules6の保存検証上限6e16を用い、rules1〜5の1e15は維持する。
