## 次に閉じる工程

1. ゲーム室: G-V2-04/05を継続。報酬指数だけを下げる案は10seedすべてで無購入の短命周回を有利にしたため不採用。次は固定報酬の見直しと自己最高の達成報酬/解放を比較する（BOKUMYAKU_REWARD_REVIEW.md）。
2. 素材室: 第一弾6点を納品済み。生成原本・プロンプト・alpha検査を保管。次の素材は敵3種/核/攻撃の表示仕様が決まった単位で依頼する。
3. ゲーム室: 第一弾を統合済み。敵と枝の視認性を維持しながら戦闘美術・読みやすさを継続改善する。完成美術とは区別する。
4. 分裂/ボスと長期育成を段階追加し、通常周回と繰返しプレイを評価。新機能に応じてテストも更新。
5. 音・UI・演出を磨き、端末QA/性能改善、最後に公開準備へ進む。美術の仕上げはシステム完成待ちにせず、統合可能な単位で並行する。
