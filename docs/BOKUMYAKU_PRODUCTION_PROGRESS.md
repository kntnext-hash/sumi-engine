## 次の工程

1. G-V2-05: 初回5〜8分の安定と長期経済。初期役割差は維持。v0.7の3案比較で分岐角を改善したが、5seedの早期敗北と育成後の記録構成の劣位が残る。次は供給条件を保った後半分岐の拡張を有限比較し、seed選別やタイマー強制終了で目標を満たさない。
2. 一人用αを実際に遊び、説明不足・操作負荷・周回テンポ・継続動機を評価する。
3. スマホ参考に合わせた縦戦場とUI、美術・音・演出。素材室に必要な敵/核/攻撃を仕様単位で依頼する。
4. 長時間/実機QAと性能改善。その後に長期機能・オンライン/課金・公開工程を個別に確定する。
