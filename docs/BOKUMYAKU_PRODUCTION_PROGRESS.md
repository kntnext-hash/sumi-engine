## 次に閉じる工程

1. ゲーム室: G-V2-04/05のビルド役割と経済を比較・設計し、次の実装判断を具体化。
2. 素材室（同時進行）: 和紙/山水背景/円相/3武器アイコンの6点を制作。仕様はBOKUMYAKU_ART_BRIEF.md。
3. ゲーム室で素材を統合し、1戦闘画面の美術と可読性を仕上げる。静止画だけでなく戦闘中に判断する。
4. 分裂/ボスと長期育成を段階追加し、通常周回と繰返しプレイを評価。新機能に応じてテストも更新。
5. 音・UI・演出を磨き、端末QA/性能改善、最後に公開準備へ進む。美術の仕上げはシステム完成待ちにせず、統合可能な単位で並行する。
