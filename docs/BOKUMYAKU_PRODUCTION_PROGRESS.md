旧rules1〜4は60Wave上限を保持。rules5以降は100000Waveの安全上限を持つが、完成コンテンツ10万面でも無限進行でもない。最大育成の固定状態では3構成が2000Wave完了まで進行継続。旧価格の有償20周ではFarmingが9周で祖墨20→21を購入、Recordは購入なし。現行価格の同条件ではFarmingは2周目に購入し10周で祖墨26、Recordは10周購入なし。追加seed11〜13では全6武器Farmingが2〜3周で初購入、Recordは3周購入なし。ゼロから全育成して到達した試験ではない。10万Waveは合成状態による境界試験であり、自然到達や長期バランスの合格ではない。現システムが動いても、収益性・継続率・端末性能の合格ではない。最新の機能検証数はQA台帳を参照。

## 次の工程

1. 研究価格の3候補比較は1.22採用で終了。価格版2の結果を基準に、長期育成と記録挑戦の動機を評価する。短い育成済み系列の購入頻度を全Lvへ一般化しない。
2. 複数seedで放置周回/記録の役割と長期経済を調整する。G-V2-05（初回5〜8分）は未合格を保持して後続調整。5seedの早期敗北、追加seedと育成後の役割差は未達のまま。60Wave打切りを外した自然進行を複数seed・同metaで比較し、恒久育成速度と長期の供給/火力配分を評価する。12条件の小標本を役割保証へ一般化せず、seed選別やタイマー強制終了で目標を満たさない。
3. 一人用αを実際に遊び、説明不足・操作負荷・周回テンポ・継続動機を評価する。
4. スマホ参考に合わせた縦戦場とUI、美術・音・演出。素材室に必要な敵/核/攻撃を仕様単位で依頼する。
5. 長時間/実機QAと性能改善。その後に長期機能・オンライン/課金・公開工程を個別に確定する。
