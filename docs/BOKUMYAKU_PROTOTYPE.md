# 墨脈 — プレイ試作 v0.2

2026-10-22。今回の範囲は3敵・60Wave上限の縦切りと自動投資の比較版。全体GDDの5敵/自然敗北ゲートや商用完成ではない。

## 見た目の方針

ユーザー提供の4枚は方向性の参考。和紙色、墨の枝、金の核/供給、朱の敵を採用。画像そのもの・画像内のロゴ/文字/素材は配布物へ取り込まない。SUMI ENGINEで枝を描き、敵と攻撃を別レイヤーで表示する。背景の山水・塔・風景や6武器は後続。

## 遊び方

Windows版はBuilds/Bokumyaku-v0.2/Bokumyaku.exe。UnityではUnitySandboxのAssets/BokumyakuPrototype/Scenes/Bokumyaku.unityを開いてPlay。投資方針と成長方針を選んで出撃し、自動迎撃で得た墨で6項目を強化する。成長方針は均衡/迎撃/集中。枝を増やすと供給が分散する。敗北後に結晶で恒久強化して再出撃する。速度切替と一時停止あり。操作欄はスクロールできる。

通常の再出撃はseedを進め、投資・成長方針を同じ起動セッション内で保持する。QA用StartRun(seed)では同じseedで強化差を比較できる。60Waveで試験終了となる場合は敗北と区別する。課金、オンライン順位、オフライン収益、自動再出撃、途中ラン再開は未実装。

## 自動投資の候補

|画面上の名前|購入方針|用途の仮説|
|---|---|---|
|手動|自動購入なし。購入先を自分で選ぶ|比較・試行用|
|広域・滲み|9末端を目標。流墨/筆速/筆幅/筆撃/滲みを順次購入|周回候補|
|多枝・火力|12末端を目標。分岐を早め、筆撃/流墨/筆速/筆撃/筆幅を順次購入|記録候補|

購入判定は30tickごと。分岐を買う順番では必要額を貯蓄する。構成固有の報酬倍率や敵弱体化はなく、戦闘・費用・報酬式は共通。途中切替と手動の追加購入も可能。自動購入時は該当行を短時間強調し、結果に生存時間・獲得墨・墨/分を表示する。墨/分は消費を差し引く前の撃破収入であり、永続結晶の効率ではない。

10seed×3構成の測定では広域・滲みが9末端、多枝・火力が12末端へ到達。自動構成の生存中央値は約8分23秒/8分25秒。手動比較群は購入を一切行わない対照群で、熟練手動プレイではない。多枝・火力が長く生存したのは10対応条件中8件だが、広域・滲みの収入効率優位は1件のみ。**周回用と記録用の役割分担、初回5〜8分の目標は未合格**。構成名で表示し、次工程で武器・標的・経済を調整する。

## 保存

Application.persistentDataPath/bokumyaku-prototype-v1.jsonへ恒久状態のみ保存。正式ゲームと別の試験用ファイル。置換前に一時ファイルを検証し、正常な旧版を.bakへ保持。破損時はバックアップを読む。破損原本は次回保存時に.corrupt-UUIDへ保護する。途中ランを復元しないため報酬はメモリ上の同一ランで一度だけ。永続runIdによる再送防止は将来の保存/オンライン工程で必要。

## 試作上の判断

- 論理座標中心0/半径360、描画384x512へ変換。描画乱数は戦闘へ影響しない。
- 固定30Hz、出現9秒/周期12秒、21600tickで試験終了。通常/高速/重装。分裂/ボスは後続。
- 高速はWave4以降25%、重装はWave8以降20%の仮分布。
- 成長は簡易脅威スコア。GDDの12sector評価は未実装。
- 滲みは古い2領域まで重複。基礎ダメージに恒久倍率を含め、先端圧は含めない。
- 敵上限96到達時はCapacityExceededで終了し報酬を出さない。
- 基礎攻撃8、射程150、成長半径150、必要撃破数4+成長回数の仮調整。外周へ達した末端も攻撃源として保持し、追加分岐は円周方向へ育つ。成長できない時は成長資源を消費しない。
- 放置周回/記録ビルドの自動投資候補を実装。筆武器6種は構想。現在の成長方針や6強化を武器システムの完成と扱わない。

## 手動評価

1. 出撃前に広域・滲みと集中を選び、出撃後も保持される。墨獲得後の自動購入で残高/Lvが変化し、分岐と枝が増える。
2. 一時停止で敵とWaveが停止し、再開する。2倍速でも同じtickの戦闘結果になる。
3. 枝の末端と攻撃開始位置が一致し、朱敵が核に届くと耐久が減る。
4. 敗北後の報酬、恒久購入、再出撃、アプリ再起動後の保持を確認。
5. 多枝・火力へ切り替えた後、手動へ戻すと自動購入が止まる。狭い画面の操作欄をスクロールし、下端の強化を操作する。
6. 人の物理入力、保存エラー表示、アプリ再起動、長時間の放置は別途手動評価する。
