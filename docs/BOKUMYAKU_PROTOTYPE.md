# 墨脈 — プレイ試作 v0.3

2026-10-22。今回の範囲は3武器・3敵・60Wave上限の縦切りと自動投資の比較版。全体GDDの5敵/自然敗北ゲートや商用完成ではない。

## 見た目の方針

ユーザー提供の4枚は方向性の参考。和紙色、墨の枝、金の核/供給、朱の敵を採用。画像そのもの・画像内のロゴ/文字/素材は配布物へ取り込まない。SUMI ENGINEで枝を描き、敵と攻撃を別レイヤーで表示する。武器は着弾点・太い払い・実際の滲み領域で描き分ける。背景の山水・塔・風景や6武器全体は後続。

## 遊び方

Windows版はBuilds/Bokumyaku-v0.3/Bokumyaku.exe。UnityではUnitySandboxのAssets/BokumyakuPrototype/Scenes/Bokumyaku.unityを開いてPlay。武器・投資方針・成長方針を選んで出撃し、自動迎撃で得た墨で6項目を強化する。成長方針は均衡/迎撃/集中。枝を増やすと供給が分散する。敗北後に結晶で恒久強化して再出撃する。速度切替と一時停止あり。操作欄はスクロールできる。

通常の再出撃はseedを進め、武器・投資・成長方針を同じ起動セッション内で保持する。QA用StartRun(seed)では同じseedで強化差を比較できる。60Waveで試験終了となる場合は敗北と区別する。課金、オンライン順位、オフライン収益、自動再出撃、途中ラン再開は未実装。

## 三つの武器

投資方針とは別に選ぶ。戦闘中も切替可能だが、既存の攻撃待ち時間は短縮されない。残った滲みは期限まで存在する。終了結果の武器名は最後に使った武器で、ラン全体の固定武器履歴ではない。

|武器|攻撃と得意な状況|代償|
|---|---|---|
|点墨|単体へ連射。孤立した高速敵を削る|同時に1体しか攻撃しない|
|貫筆|標的方向の直線に最大3体。並んだ敵と遠い敵へ届く|単体威力0.8倍、攻撃間隔1.35倍|
|滲墨|着弾後1.6秒残る円形の範囲。遅い密集敵へ継続ダメージ|直接威力0.45倍、間隔1.1倍。速い敵は範囲を抜ける|

仮数値: 点墨の威力/射程/間隔を1とする。貫筆は射程1.2倍、半幅12+2×筆幅Lv、前方線分の射影距離→敵ID順に3体。滲墨は半径32+3×筆幅Lv+2×滲みLv、秒ダメージは基礎威力×末端墨圧×0.85×(1+0.12×滲みLv)。全滲み領域は古い2領域まで重複、96領域上限、満杯では新しい領域を生成しない。表示領域と戦闘判定は同じ座標/半径を読む。

点墨/貫筆の「滲み」強化は従来の0.7秒場を発生させる。こちらは基礎威力×0.08×滲みLv/秒で末端墨圧を含めない。滲墨武器にはこの旧場を二重生成せず、専用場を強化する。供給分散に対する挙動が異なるため、比較で混同しない。

## 自動投資の候補

|画面上の名前|購入方針|用途の仮説|
|---|---|---|
|手動|自動購入なし。購入先を自分で選ぶ|比較・試行用|
|広域・滲み|9末端を目標。流墨/筆速/筆幅/筆撃/滲みを順次購入|周回候補|
|多枝・火力|12末端を目標。分岐を早め、筆撃/流墨/筆速/筆撃/筆幅を順次購入|記録候補|

購入判定は30tickごと。分岐を買う順番では必要額を貯蓄する。構成固有の報酬倍率や敵弱体化はなく、戦闘・費用・報酬式は共通。途中切替と手動の追加購入も可能。自動購入時は該当行を短時間強調し、結果に生存時間・獲得墨・墨/分を表示する。墨/分は消費を差し引く前の撃破収入であり、永続結晶の効率ではない。

v0.3は10seed×3構成×3武器=90条件を比較。全条件が自然敗北で終了。広域・滲みの生存中央値は点墨502.52秒、貫筆426.88秒、滲墨516.62秒。多枝・火力では505.05/492.80/249.88秒。武器と投資の相性が出たが、**周回用と記録用の経済的な役割分担、初回5〜8分の一貫した達成は未合格**。手動群は無購入対照で、熟練手動プレイではない。

結果には結晶/分も表示する。現報酬式は突破Waveを強く評価するため、長く生きる構成は結晶/分も上がりやすい。短い周回で稼ぐ構成と最高記録を伸ばす構成を分けるには、今後Tierや報酬曲線を明示的に評価する必要がある。武器名だけで用途の完成を主張しない。

## 保存

Application.persistentDataPath/bokumyaku-prototype-v1.jsonへ恒久状態のみ保存。正式ゲームと別の試験用ファイル。置換前に一時ファイルを検証し、正常な旧版を.bakへ保持。破損時はバックアップを読む。破損原本は次回保存時に.corrupt-UUIDへ保護する。途中ランを復元しないため報酬はメモリ上の同一ランで一度だけ。永続runIdによる再送防止は将来の保存/オンライン工程で必要。

## 試作上の判断

- 論理座標中心0/半径360、描画384x512へ変換。描画乱数は戦闘へ影響しない。
- 固定30Hz、出現9秒/周期12秒、21600tickで試験終了。通常/高速/重装。分裂/ボスは後続。
- 高速はWave4以降25%、重装はWave8以降20%の仮分布。
- 成長は簡易脅威スコア。GDDの12sector評価は未実装。
- 持続領域は全武器を通じて古い2領域まで重複、最大96領域。点墨/貫筆の「滲み」強化は基礎ダメージに恒久倍率を含め先端圧を含めない。滲墨の固有領域は先端圧も含む。
- 敵上限96到達時はCapacityExceededで終了し報酬を出さない。
- 基礎攻撃8、射程150、成長半径150、必要撃破数4+成長回数の仮調整。外周へ達した末端も攻撃源として保持し、追加分岐は円周方向へ育つ。成長できない時は成長資源を消費しない。
- 放置周回/記録ビルドの自動投資候補と3武器を実装。6武器全体や武器装備/解放/固有研究は後続。

## 手動評価

1. 出撃前に滲墨・広域・滲み・集中を選び、出撃後も保持される。墨獲得後の自動購入で残高/Lvが変化し、分岐と枝が増える。
2. 一時停止で敵とWaveが停止し、再開する。2倍速でも同じtickの戦闘結果になる。
3. 枝の末端と攻撃開始位置が一致し、朱敵が核に届くと耐久が減る。
4. 敗北後の報酬、恒久購入、再出撃、アプリ再起動後の保持を確認。
5. 武器を滲墨→貫筆→点墨へ変更し、領域/払い/着弾の違いを確認。多枝・火力へ切り替えた後、手動へ戻すと自動購入が止まる。操作欄をスクロールし、下端の強化を操作する。
6. 人の物理入力、保存エラー表示、アプリ再起動、長時間の放置は別途手動評価する。
