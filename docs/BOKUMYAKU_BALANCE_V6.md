# 墨脈 v0.6 — 稼ぎと記録の投資差

2026-10-22 JST。開始HEAD ec15566。G-V2-04/05を継続。Unity6000.3.26f1、既存Engine/BrushLabは変更しない。

## 仮説と比較

まず敵/報酬を変更せず購入順のみを比較した。旧2構成120条件＋3候補180条件。供給を育ててから枝を増やすBや修復優先Cは到達を改善する条件があったが、『記録の深度↑と放置の結晶/分↑』を同時に満たす比較は0/180。到達と効率の相関0.9972はこの条件群の記述値であり因果や有意差の証明ではない。証拠balance-v6-candidates/analysis.json。

この結果を受け、購入順だけの探索を終了し、収益への投資機能を1種類追加する。これは追加3候補の経済実験として元の探索と分けて記録する。未達を隠すために勝率閾値・seed・武器を変更しない。

## 採墨

- 既存6強化を維持し、第7周回強化Harvest（採墨）を追加。どの構成でも墨を払って購入できる。
- 購入後の有効撃破から得る通常結晶の点数を増やす。購入前へ遡及しない。子敵は0のまま。墨収入・成長・攻撃・敵強度は増減させない。
- 火力・供給・枝へ使える墨が減ることが代償。構成名を見て報酬を上乗せしない。
- 放置候補はWave15以降に採墨を含める。記録候補は供給先行Bを採用し採墨を買わない。自動修復を同時に混ぜず、効果を区別する。
- コスト/倍率は最大3候補で比較。決定値は実コードと最終測定を正本とする。

## 事前固定した判定

- 通常効率 = 通常結晶×60/(戦闘秒+再出撃待機3秒)。一度きりの最高記録ボーナスは除外。
- 深度 = 完了Wave。表示中の未完Waveを加えない。
- 同seed/同武器/Balanced/meta0でFarmingとRecordを比較する。主条件Pointのseed1..10で、放置効率勝ち/記録深度勝ちを各8/10以上。全6武器60組で各48/60以上、各武器6/10以上も頑健性条件。引分は勝ちに数えない。中央値/平均/組別差分も掲載し、効果量に後付けの閾値を設けない。
- 標準初回はFarming/Point/Balanced/meta0。固定seed1..10の全件300〜480秒。追加seedでも全件確認。実行上11..20を全候補で測ったため、独立holdoutとは扱わない。候補固定後に未使用21..30を別途測定する。達成しなければG-V2-05は未合格。
- 製品の初期選択は完全新規データだけFarmingとし、既存構成を上書きしない。

## 保存と旧ルール

新規周回はrules2、v0.5で中断した周回はrules1の旧AutoBuyを維持する。切替操作で周回のrulesを変えない。Snapshot schema1/旧6levels/旧精度payloadを読み、schema2へ規則を明記して保存する。履歴にも規則を残す。

保存先はcampaign-v3/schema3。旧campaign-v2を読み、結晶/研究/最高/履歴/3構成/active/runIdを別ファイルへコピーする。原本とbakを維持。新v3が壊れている場合に古いv2へ巻き戻さない。旧Playerは旧v2だけを使うため、移行後に旧Playerで進めた分の自動合流はしない。
