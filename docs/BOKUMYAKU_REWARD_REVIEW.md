## 比較条件

`w = completedWave`、報酬 `floor(4 + 0.25 × w^p)`、ただしw=0は0。指数pだけを1.4 / 1.2 / 1.0に変更した3候補。係数0.25と固定加算4は共通。

効率は `報酬 × 60 / (既存測定の生存秒 + 自動再出撃待ち3秒)`。戦闘・所得・Wave・seedは一切再計算していない。保存の所要時間、操作時間、連続周回による恒久成長は含めない。

## 判定

**指数を下げるだけの変更は採用しない。** 現行は深いWaveと効率がほぼ同方向であり、RecordとFarmingの目的を分離できていない。一方、1.2または1.0に下げると全10seedで無購入Manualが最高効率になった。これは短命周回を促す方向で、投資して枝を育てる意義を弱める。

Waveがおおむね時間に比例する区間では、効率には `4 / 時間` と `w^p / 時間` が混在する。指数を下げると後者の長期成長が弱まり、固定加算4と整数切捨てが短い周回に有利になる。w=0を0にしても、少数Wave後の早い敗北による偏りは防げない。3秒待機を含めても今回の逆転は残った。

Manualは**何も購入しない対照条件**であり、熟練者の手動プレイではない。また90行は同じ10seedを再利用した対応条件で、90独立標本ではない。相関はこの標本の記述値であり、因果・有意差・将来の優位を保証しない。
