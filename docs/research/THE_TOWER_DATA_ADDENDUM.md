# The Tower 追加データ調査

調査日: 2026-10-21 JST。目的は提供済み引継ぎの不足補完。アプリ実測・APK解析・SDK実行は未実施。以下の「掲載」は資料上の主張であり、現行アプリとの一致を保証しない。

## 1. 見つかった計算資料

[TheTowerSDK](https://github.com/TmRxJD/TheTowerSDK) は敵Wave成長、強化費用、研究・カード等のデータと計算を公開する非公式プロジェクト。READMEにゲーム29.1対応の記述がある。全機能・全データが29.1実測済みという意味ではない。

- 敵のHP/攻撃力のTier・Wave依存、敵種倍率、出現率を調べる入口がある。
- 恒久強化と研究の費用、効果、上限を比較する入口がある。
- 戦闘履歴を読む機能もあるが、今回は個人セーブの取得・復号・実行なし。
- READMEは既存スプレッドシートとの計算不一致も明示する。参照計算器であって正解判定器にはしない。

確認したGitHubファイルblob SHA（リポジトリcommit SHAではない）:

[LICENSE](https://github.com/TmRxJD/TheTowerSDK/blob/main/LICENSE) はMIT。ただし [NOTICE](https://github.com/TmRxJD/TheTowerSDK/blob/main/NOTICE) はISC由来部分、Effective Paths表の出所、抽出補助由来部分のライセンス条件未確定も記載する。SDK全体のMIT表記だけで全収録資料を墨脈へ直接持ち込めるとは判断しない。今回は出所付きの調査参照のみ、コード・表・画像の取り込みなし。

**短縮できる工程:** 手作業で費用曲線や敵成長を探す時間。**残る工程:** 墨脈独自の枝供給、衝突・標的、遊びやすさ、Unity実表示の実装と検証。取得したTower値を既存CSVへ上書きしない。

## 2. 大会：具体値と資料の食い違い

[Towerstats大会ガイド](https://towerstats.org/guide/tournaments/)（ページ更新表記2026-10-07、非公式）は30人、週2回、水・土00:00 UTC（日本09:00）、7リーグを掲載。最上位Mythicは1位475 Stones/50 Keys、最下位225 Stones/8 Keysを掲載する。現行アプリ照合前の参考値とする。

同ページは全リーグでIntro Sprint Mastery自動適用とするが、[公式8月26日告知](https://www.techtreegames.com/post/v29-is-rolling-out) はCopper/Silverを除く変更を説明している。**ガイドの更新日が新しいだけでは正確とは言えない。大会挙動は公式の変更履歴を優先し、最終的には対象版で確認する。**

墨脈への追加評価要件:

1. 下位リーグ上位と上位リーグ下位を、2大会以上の累積報酬で比較する。
2. Stones相当とKeys相当を別々に比較し、片方の改善で他方の損失を隠さない。
3. 昇格直後に育成が止まらないか、参加・到達報酬を含めて検査する。
4. 通常周回と大会のルール差を設定で明示する。報酬表、順位判定、受取履歴の版を保存する。

上記は墨脈向け検証案。Towerと同じ人数・日程・値を採用する決定ではない。

## 3. 成長：同じ能力に異なる費用・期間がある

[Workshopガイド](https://towerstats.org/guide/workshop/)（2026-10-07、非公式）では、ラン外のCoin購入が開始レベルを上げ、ラン内Cash購入はその周回だけ有効。強化項目間で上限も大きく異なる（掲載例: Damage 6000、Attack Speed 99）。

設計上の示唆は、全強化を同じ指数式・同じ上限に揃える必要がないこと。墨脈では供給・火力・速度・範囲ごとに、購入までの秒数、購入後の実効DPS増分、敗北Wave増分を測る。現在の共通費用式は初期仮説として保持し、実走前にTowerの費用表へ置換しない。

## 4. 課金：確認範囲と残る穴

[公式Premium Pass説明](https://techtreegames.zendesk.com/hc/en-us/articles/50437898976155-Premium-Pass-Rewards) で無料/有料報酬列と進捗条件を確認済み。価格一覧だけでは購入価値を説明できないため、次は「権利の永続性、倍率の重複、進捗条件、復元、地域/ストア/版」を一組で記録する。

Starter/Epic/広告解除の正確な現行倍率・重複、販売画面の日本価格、提示タイミングは今回の一次資料調査では確定できなかった。非公式検索結果だけから採用値を確定しない。購入や課金実装は行っていない。

## 5. まだ不足するものと実装への扱い

|不足|次の確認方法|今の扱い|

追加資料を待つことをG1/G2の必須条件にはしない。既存BOKUMYAKU式で独立シミュレーションを作り、上記の指標を出せることが次の実装成果物。
