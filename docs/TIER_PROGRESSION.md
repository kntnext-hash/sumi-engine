# 段位とWaveの分離

2026-10-23、ユーザー指示。画面の呼称は「段位」、コードの識別子はTier。Waveは各周回の進行数で出撃ごとに1へ戻り、段位は難易度選択。各段位の最高完了Wave/初達成報酬を独立保持する。恒久研究は共通。

HPは既存Wave基礎HP×段位倍率。倍率はWave1〜100を線形補間し、それ以後は固定。既存長期曲線の式/10万Wave上限を変更しない。TierBalanceに表と計算を分離。数値は仮値で、収益/時間・到達の受入未実施。2026-10-24にライブ戦闘/保存/UIへ接続済み。通常結晶へ倍率を適用、初達成報酬は従来の5波ごと5結晶を段位別に保持。

The Towerの難易度Tier/報酬倍率/前TierのWave100解放の構造を参考にする。数表/コード/画像はコピーしない。参照: https://towerstats.org/guide/tiers/ （2026-10-23検索確認）。内部TierとWaveを混同せず、例「幽墨・二段 / WAVE37」と表示する。

## 成長とコンテンツ
- 結晶は恒久研究用の収益倍率として段位表で管理。研究価格は別表で調整。周回内の墨は当初現状を保持し、結晶倍率で戦闘内購買まで二重加速しない。
- 高段位の浅い周回と低段位の深い周回を結晶/分でも比較する。最高段位が常に最高稼ぎとは決めない。
- 二段を吸生種/護輪種の導入先とする。別の敵挙動/対処法として実装するまでは、既存5種の見た目だけ変えて実装済みとはしない。三段は敵構成の組合せを強化。
- 昼/夜/朱の背景は再利用する山水素材へ色調/階調を適用する。UI文字と赤敵/金味方の視認性は段位ごとに確認。
- 初週目標は一段でのWave深度と二段解放/進入へ分けて評価する。段位追加だけで現在の育成不足が解消したとは扱わない。

## 段位の採用方針の再確認（2026-10-24）
ユーザー提案に沿い、プレイヤー向け名称は段位に統一する。Waveは周回の深さ、段位は難度・結晶倍率・背景・敵解禁の組合せ。現在は初墨・一段/幽墨・二段/朱天・三段を実装済み。
高段位の倍率だけでは研究の停滞解消を保証できない。研究価格÷実際の結晶/分で購入までの時間を比較し、低段位の放置周回と高段位の記録挑戦の使い分けを残す。二段以降の収益/分は未検証であり、現倍率は暫定。段位背景と敵解禁で変化を付け、段位だけ増やした状態を内容の完成とは扱わない。
