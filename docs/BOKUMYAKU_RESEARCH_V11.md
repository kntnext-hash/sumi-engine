# 墨脈 v0.11 — 研究費用と育成テンポ

基点94606b8。v0.10は育成済み状態からでも祖墨20→21に採墨周回9回を要した。今回は研究価格のみを調整し、戦闘rules6・能力倍率・上限・敵・撃破報酬を維持する。

## 価格の契約

- 購入前Lv0〜10の価格は旧式ceil(基礎価格×1.48^Lv)を保持する。Lv10→11も旧価格。
- 購入前Lv11〜20はceil(丸め済み旧Cost10×1.22^(Lv−10))。4研究共通の曲線で、基礎価格は祖墨8/深根10/生脈8/豊穣12。
- 祖墨Lv21〜100はceil(新Cost20×(1+0.05×(Lv−20))²)。祖墨上限100、他20は維持。
- 現行価格識別はResearchPriceVersion=2。購入履歴を保存する監査システムではなく、実行コードと検証資料の価格識別子。
- 保存先v8へコピー移行。所持Lv、残高、履歴、途中戦闘は変更しない。既払い分を再計算した返金は行わず、v7以下の原本とバックアップを保持。schema3と戦闘rules6は変えない。
- 研究画面は祖墨の現在倍率→次Lv倍率を表示。価格計算はMeta.Costに統一し、購入可能判定と引落しを一致させる。戦闘中研究不可・保存失敗時不変を維持する。

## 有限比較と判定

後半指数1.18/1.22/1.26の3候補と旧版を比較。各76周: 育成済みmeta20からEnsoのFarming/Record各10周、全0からEnso Farming20周、全20から6武器×2構成各3周。開始残高0、通常報酬のみ、支出を実際に引落し、初達成ボーナスは含めない。

全0の購入方針は未上限の最低Lv優先、同Lvなら祖墨→深根→生脈→豊穣。選んだ研究が買えなければ貯蓄する。これは検証方針であり、自動研究購入をゲームへ追加したものではない。

1.22は選定seed1〜3の全6武器Farmingで1〜3周以内の初購入目安を満たす中間案。目安はmeta20からの比較専用で、全レベルの購入頻度保証ではない。固定後seed11〜13、候補と製品一致、全価格域・保存移行・実UI・Windowsを別に検査する。

結果はevidence/research-v11-*とQA台帳。長期経済全体、全武器の記録優位、数万Wave攻略、実時間放置、モバイル性能は未達のまま。価格候補を無期限に増やさない。
